ribban här HÖGRE än demo-förbudslistan.

**Palett som får användas i nutid** (ur inventeringens "Kan visas/lovas UTAN
att ljuga idag", 2026-07-15):
- Missat samtal → SMS (Tier 0). 46elks-routing **LIVE**.
- CRM + offert + faktura + ROT-**beräkning** med årstak + veckovärde i kronor.
- Produktbank/sammansatta produkter/visningsfilter — **BYGGT★** (v67 körd i
  prod, verifierad mot pilotdata). Får beskrivas, INTE kallas "beprövad i drift".
- Gatad proaktiv reaktivering (Hanna) + Förtroendetrappan som **koncept**
  ("förtjänar", aldrig "brukar").
- Matte-chatt på webben (text).
- Idag-vyn/godkännandekön (LIVE i prod).

**Aldrig i text (hårdare än demolistan):**
- ❌ Röstagent som pratar i telefon (SPEC — finns inte)
- ❌ Fortnox som "ingår"/"gratis" (licens-blockerat; säg "synkar till" eller inget)
- ❌ Skatteverket-direktinlämning (ROT-filen är aldrig skarpt inlämnad)
- ❌ Golden Path/CRM-flödet som "bevisat" (BYGGT, ej prod-verifierat)
- ❌ Mobilens senaste funktioner (branch, inte på telefon)
- ❌ Konkreta kundsiffror/resultat (case-studyn finns inte än)
- ❌ Drift-historik för BYGGT-funktioner ("brukar", "hundratals", "varje dag")

**Hanteringsregel för BYGGT (ej ★):** beskriv VAD funktionen gör, aldrig hur
väl den presterat. Ingen resultatstatistik, inga superlativ om utfall. Vid
minsta tvekan: framtidsform ("bygger mot", "utvecklas för att").

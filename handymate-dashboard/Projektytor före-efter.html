Projektytor — före/efter

Fem konkreta rättningar i projektöversikten och projektdetaljvyn, var och en visad mot dagens produktionskod. Sist en token-patch som tar bort grundorsaken till färgdriften.

01

Projektöversiktens rader

Blandade neutraler (gray-* i raderna, slate-* i jobbtyp-chipsen), himmelblå fakturabadge och tre staplar per rad. Efter: en slate-skala, semantisk badge, och bara den stapel som faktiskt begränsar jobbet — resten som siffror.

04

Kort, knappar, radier

card-base i globals.css ritar #e5e7eb mot brandens #E2E8F0, och tailwind.config har inga shadow-tokens — därför är skuggorna ad hoc. Primärknappen är platt teal-700; branden är gradient plus teal skugga. I nya-projekt-modalen blandas radie 12 och 8.

05

Radera projekt

Raderingen går via webbläsarens confirm(). Den bryter varumärket helt, kan inte visa vad som faktiskt försvinner, och ser identisk ut oavsett hur allvarlig åtgärden är.

  • Samma modal återanvänds för alla destruktiva åtgärder i appen.
06

Token-patchen

Grundorsaken till att blått kommer tillbaka: secondary i tailwind.config är en sky-skala. Så länge den finns kommer nya komponenter plocka den i god tro. Tre filer, ungefär tjugo rader.

tailwind.config.ts + app/globals.css
tailwind.config.ts — theme.extend.colors
- secondary: { 50:'#f0f9ff', 100:'#e0f2fe', 500:'#0ea5e9', 700:'#0369a1' }, // sky = källan till färgdriften
+ // secondary borttagen. Neutralerna är slate, accenten är teal.
+ status: {
+ plan: { bg:'#f1f5f9', fg:'#475569' }, // slate — ej igång
+ active: { bg:'#f0fdf9', fg:'#0f766e' }, // teal — pågår
+ action: { bg:'#fef3c7', fg:'#b45309' }, // amber — kräver handling
+ done: { bg:'#d1fae5', fg:'#047857' }, // emerald — klart / betalt
+ risk: { bg:'#fee2e2', fg:'#b91c1c' }, // red — risk
+ },
tailwind.config.ts — theme.extend.boxShadow (saknas helt idag)
+ xs: '0 1px 2px rgba(15,23,42,.04)',
+ sm: '0 2px 8px rgba(15,23,42,.05)',
+ md: '0 8px 24px rgba(15,23,42,.06)',
+ lg: '0 20px 40px rgba(15,23,42,.08)',
+ brand: '0 10px 25px -5px rgba(13,148,136,.25)',
app/globals.css — .card-base
- border: 1px solid #e5e7eb;
+ border: 1px solid #e2e8f0;
- &:hover { border-color: #d1d5db; }
+ &:hover { border-color: #cbd5e1; }
Sök-och-ersätt efteråt: gray- → slate- i app/dashboard/projects/, och de fem bg-blue-50 / bg-purple-50 / bg-sky-100-förekomsterna till status.*.

# Du startade inte företag för att administrera ett gammalt system.

Ändå börjar varje dag med samma jakt: Vem väntar på svar? Vad ska faktureras?
Vilken offert behöver följas upp? Vad lovade vi kunden? Vilket projekt behöver
min uppmärksamhet?

Handymate är byggt för 2026. Ett sammanhängande system för hantverksföretaget,
med ett AI-team som ser sammanhanget och hjälper arbetet framåt.

**[Hälsa på ditt nya team]**

## En ingång. Ett helt team.

Du behöver inte lära dig vilken agent som kan vad. Säg till chefsagenten Matte
vad du vill uppnå. Han samlar rätt specialister, visar planen och håller ihop
resultatet.

- **Lisa** fångar nya och missade samtal, skapar affären och återkopplar via
  SMS när du inte hann svara.
- **Daniel** arbetar med leads, offerter, ÄTA och återaktivering.
- **Lars** håller koll på projekt, tid, material, bevis och marginalrisk.
- **Karin** ser faktureringsmöjligheter, betalningar och ekonomiska nästa steg.
- **Matte** koordinerar teamet och ger dig en tydlig väg framåt.

## Kundkontakt utan att kunden behöver jaga

Kundportalen samlar dokument, status och dialog kring arbetet. Handymate hjälper
er följa upp vid rätt tillfälle och gör det lättare att hålla relationen levande
efter det första jobbet.

## Ge teamet ett Uppdrag

“Fyll nästa veckas luckor.” “Följ upp gamla badrumskunder.” “Frigör pengar före
månadsskiftet.” Uppdraget kan leva över tid, arbeta genom flera specialister och
visa vad som är klart, vad som väntar och vad som inte gick att bedöma.

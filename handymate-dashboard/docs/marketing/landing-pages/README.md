# Lanseringslandningar

Tre resultatsidor för handymate.se. De säljer samma produkt från tre
köpintentioner och använder samma bevisföring, priser och CTA. Publicera dem
på webbplatsen — inte i den inloggade appen.

| Sök-/köpintention | Rekommenderad URL | Fil |
|---|---|---|
| Få bättre betalt för redan utfört arbete | `/hitta-pengar` | `hitta-pengar.md` |
| Se risk innan marginalen försvinner | `/skydda-marginalen` | `skydda-marginalen.md` |
| Slippa hålla ihop administrationen själv | `/slipp-administrationen` | `slipp-administrationen.md` |

Gemensamma regler:

- Matte presenteras som **chefsagenten**.
- Funktionen heter **Uppdrag**, aldrig Mission Control utåt.
- Inga påhittade kundbelopp, besparingar eller procentsiffror.
- CTA går till befintligt köp-/onboardingflöde.
- Prisblock ska läsa samma publicerade prisdata som köpflödet. Duplicera inte
  siffrorna i sidkoden.
- Lisa beskrivs enligt den verifierade samtal → lead → SMS-kedjan, inte som en
  komplett talande röstagent.

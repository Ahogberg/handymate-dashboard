# LinkedIn-serien: Framtidens hantverksföretag

Sju publiceringsfärdiga long-form-artiklar för LinkedIn. Serien utbildar
marknaden om ett nytt arbetssätt och låter Handymate bli den naturliga
slutsatsen, inte en påklistrad annons.

## Newsletter

**Namn:** Framtidens hantverksföretag

**Beskrivning:** Om hur AI, automation och bättre arbetssätt kan göra
hantverksföretag lönsammare — utan mer administration.

**Primär avsändare:** Andreas personliga profil. Handymates företagssida delar,
kommenterar och återpublicerar relevanta utdrag. När företagssidan har tillgång
till Page Newsletter kan serien även samlas där.

## Publiceringsformat

Varje fil innehåller redaktörsnoteringar före den horisontella linjen. Kopiera
artikeltexten efter linjen till LinkedIn. Omslagen ligger i:

`public/marketing/content-library-v1/article/`

LinkedIns rekommenderade omslagsformat är 1920×1080 px. Lägg till två
inlinebilder där filen anger det. Använd verkliga produktbilder när artikeln
visar Handymate; syntetisk UI är förbjuden.

## Återbruk per artikel

Varje artikel ska också ge:

1. ett kort grundarinlägg med artikelns kärnfråga,
2. en karusell med 5–7 slutsatser,
3. ett kort videomanus,
4. två fristående citatbilder,
5. en fråga till kommentarsfältet.

Mät sparningar, kvalificerade kommentarer, profilbesök, newsletter-
prenumerationer och demosamtal. Optimera inte för reaktioner utan affärsvärde.

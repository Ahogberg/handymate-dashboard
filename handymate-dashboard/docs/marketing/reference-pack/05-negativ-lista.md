# 05 · Negativ lista — kassera klippet om något av detta syns

Ordningen är efter hur ofta det faller.

## Alltid kassera
1. **Händer** — fel antal fingrar, fingrar som smälter i verktyg, händer som griper fel.
2. **Pseudotext** — bokstäver, skyltar, etiketter, "svenska" ord som inte är ord. Även på pärmar, kläder, skåpbilen.
3. **Skärmar som visar något** — varje skärm ska vara vänd bort, släckt eller oskarp. UI läggs alltid i post från riktig produkt.
4. **Identitetsdrift** — agentens ansikte, ålder, frisyr eller garderob ändras inom klippet eller mot porträttet.
5. **Osvensk miljö** — amerikansk byggarbetsplats, hard hats i onödan, pickup, gipsvägg-öken, palmer, gula skolbussar.
6. **Logotyper och varumärken** — på kläder, verktyg, bil, kaffemugg. Även Handymate-märket (det läggs i post).
7. **AI-visuella klichéer** — hologram, glödande UI, robotar, pengaregn, blå/lila neon, partikelmoln, "data" som flyter.
8. **Fysik** — verktyg utan vikt, dörrar som öppnas fel, kaffe som inte rör sig, hår som fastnar.

## Kassera i annonser (kan vara ok i intern test)
9. Reklamfilmsposing — modellen ler mot kameran utan anledning, "hero"-vinkel underifrån, slow-motion-glädje.
10. Testimonial-känsla — någon som ser ut att prata *om* produkten till kameran (förutom Andreas på riktigt).
11. Kunden som skådespelar reaktion — överdrivet leende åt telefonen, lättnadssuck.
12. Två agenter i samma bild.

## Kassera på sanningsgrund
13. Belopp, siffror, procent — även på whiteboard, kvitto eller i bakgrunden.
14. Något som ser ut som ett riktigt affärssystem eller en riktig konkurrents gränssnitt.
15. Lisa i något som liknar ett pågående telefonsamtal.
16. Matte som utför hantverket.

## Behåll bara om
- Klippet överlever ovanstående **och** går att klippa till 2–4 sekunder **och** matchar ljus/färg med föregående godkända klipp i samma film.
